动态批次迭代 (7)          推理调度核心概念            动态批次迭代 (7)

名称
       动态批次迭代 — 以单次模型前向为周期，每次重构批次并回收资源
       的细粒度调度机制（亦常称为 迭代级调度 或 连续批处理）

备注
       阁下所指“迭代级批次重构”，在 vLLM 及相关推理系统中已
       抽象为一项核心调度概念，常以以下专名指称：

       · 连续批处理 (Continuous Batching)
       · 迭代级调度 (Iteration-Level Scheduling)
       · 动态批次迭代 (Dynamic Batching at Iteration Granularity)

       其中，连续批处理 最为通用，迭代级调度 更强调执行边界与决策
       时机，而 动态批次迭代 直接点明“以迭代为周期动态重组批次”
       的本质。

       此概念主张：
           batch 并非持久任务组，而是每次 GPU 开工前临时构造的
           输入集合。调度器在每次迭代结束点统一完成 增（新请求）、
           删（已完成序列）、改（prefill 状态切换）、释放（回收
           已完成序列的物理 KV 块），使 GPU 利用率始终紧贴负载
           变动，无木桶短板空转。

       正是由于将此机制抽象为独立概念，才能让 PagedAttention、
       分块预填充、前缀缓存等技术在统一的迭代节拍中协同运转。

参见
       continuous-batching(7), llm-iteration(7), vllm-arch(7)

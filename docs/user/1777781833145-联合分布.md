JOINT-DISTRIBUTION(7)          概率论基础                JOINT-DISTRIBUTION(7)

名称
       joint-distribution — 多元随机变量的完整概率描述，所有推理
                            与生成模型的数学原点

概述
       联合分布 P(X₁, X₂, ..., X_T) 以单一函数刻画多个随机变量同时
       取特定值的概率。它是一切统计学习与序列模型的基础语言。由于
       高维空间指数级增长，直接建模不可行，由此催生了分解、条件独立
       假设与自回归等结构化表示。

描述
       本手册沿问题链展开联合分布的定义、高维灾难、链式分解以及该
       分解如何引出自回归模型与 Transformer 架构。

       问题 0 · 如何处理多个变量同时发生的概率？
       │
       ├── 单一变量：分布 P(X) 描述 X 取每个值的概率，易于定义或估计。
       │
       ├── 多个变量：我们关心多个变量同时取值的概率，如
       │       P(X₁=x₁, X₂=x₂, ..., X_T=x_T)
       │   例如“句子‘早上好’中三个token同时出现的概率”。
       │
       ├── 正式定义：
       │       设随机向量 X = (X₁, X₂, ..., X_T)，其联合概率质量函数为
       │           P(X₁=x₁, X₂=x₂, ..., X_T=x_T)
       │       满足：所有概率非负，且对所有可能值的组合求和为 1。
       │       连续情况则用联合概率密度函数 f(x₁,...,x_T)。
       │
       └── 联合分布是完整的信息载体，所有关于这些变量的任何边缘或
           条件概率均可由它推出。但直接处理它面临维度灾难。

       问题 1 · 为什么不直接建模联合分布？
       │
       ├── 维度爆炸：
       │   若每个变量 X_t 有 V 种取值（如词表大小 50000），
       │   T 个变量的联合分布需要 V^T 个参数。
       │   即使 T=10 个小变量，参数量已达 9.7×10⁴⁶，完全不可行。
       │
       ├── 数据稀疏：
       │   大部分取值组合在数据中从未出现（零频率），无法可靠估计。
       │   朴素计数法在大 T 下彻底失效。
       │
       ├── 推论：必须引入结构性假设，将全局分布压缩为可学习的参数
       │   化形式。
       │
       └── 最普遍的结构工具是概率链式法则。

       问题 2 · 如何利用链式法则结构化解联合分布？
       │
       ├── 恒等式（无损失，总是成立）：
       │       P(X₁, X₂, ..., X_T) = 
       │           P(X₁) · P(X₂|X₁) · P(X₃|X₂,X₁) · ... · P(X_T|X_{<T})
       │       即有序地将每个变量对历史的依赖条件化。
       │
       ├── 自回归约简：
       │   假设每个条件分布可以通过有限窗口或参数化模型（如
       │   Transformer）来近似。则模型只需学习 T 个条件分布的参数，
       │   而非 V^T 个原子概率。
       │
       ├── 参数化形式：
       │       设模型 f_θ 输入历史上下文，输出对下一个 token 的条件分布。
       │       训练目标为最大化联合似然：
       │           max_θ  Π_{t=1}^T f_θ(x_t | x_{<t})
       │       等价于最小化负对数似然（交叉熵）：
       │           L(θ) = -Σ_{t=1}^T log f_θ(x_t | x_{<t})
       │
       └── 此即自回归模型的训练根基。但仅有链式法则还不够——
           模型架构必须能有效、并行地计算所有条件分布，引出因果注意力的设计。

       问题 3 · Transformer 如何高效实现此有条件建模？
       │
       ├── 因果自注意力（Causal Self-Attention）：
       │   对于位置 t，注意力机制通过上三角掩码（mask）强制仅关注
       │   位置 1..t，屏蔽未来位置 t+1..T。
       │        Attention(Q,K,V) = softmax( (QK^T / √d) ⊙ mask ) V
       │   mask_{ij} = 0 若 i < j，否则 1（或附加 -∞ 加法）。
       │
       ├── 并行训练：
       │       给定完整序列 X ∈ R^{T×d}，单次 forward 可并行计算
       │       所有位置的条件分布。掩码保证位置 t 的输出仅依赖
       │       1..t，满足链式法则的顺序约束，而无需串行 t 次。
       │       计算复杂度 O(T² d)（注意力）+ O(T d²)（投影）。
       │
       ├── 生成时：
       │   必须逐 token 串行，因为 t+1 步需先前步的采样结果。
       │   所以训练高度并行，推理受串行约束。
       │
       └── 这个差异正是 KV 缓存、连续批处理等一切推理优化的来源，
           因为每步都需要携带逐步增长的历史状态。

       问题 4 · 除了自回归，有无其他结构化联合分布的方法？
       │
       ├── (A) 马尔可夫假设：
       │       P(X_t | X_{<t}) ≈ P(X_t | X_{t-k}, ..., X_{t-1})
       │   仅依赖最近 k 步，经典于 HMM、n-gram 语言模型，性能有限。
       │
       ├── (B) 条件独立图（贝叶斯网络）：
       │   一般化形式，指定每个变量仅依赖其父节点。自回归是全序链，
       │   马尔可夫是 k 阶截断链。
       │
       ├── (C) 隐变量模型：
       │   引入潜变量 Z，假设变量间条件独立于 Z：
       │       P(X₁,...,X_T) = ∫ P(Z) Π_{t=1}^T P(X_t|Z) dZ
       │   此类模型（如 VAE、扩散模型）在生成任务中普遍但不直接适用于
       │   严格有序的文本生成。
       │
       └── 对于自然语言这种严格有序的序列，自回归链式分解已被证明
           是扩展性最高、质量最稳定的选择，主导了 GPT 系列、LLaMA 等
           所有大模型的基本框架。

结论
       联合分布是所有概率建模的起点，其高维度迫使引入结构化分解。
       概率链式法则将联合分布无损拆解为有序条件分布的乘积，自回归
       模型化其为逐 token 预测任务。Transformer 以因果自注意力在
       训练时并行、在推理时串行地实现这一范式。理解联合分布的分解
       原则，即理解了从数学到架构、从训练到推理优化的完整动机链。

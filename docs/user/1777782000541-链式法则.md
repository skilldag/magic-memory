CHAIN-RULE(7)               概率论与统计                 CHAIN-RULE(7)

名称
       chain-rule — 将联合概率分布无损分解为条件分布之积的恒等式

概述
       概率链式法则（乘法法则的推广）将高维随机变量的联合分布
       转化为有序的一维条件分布乘积。它是自回归生成、贝叶斯推断、
       损失函数构造与掩码语言建模的共同数学骨架。

描述
       本手册以问题推导链展示链式法则的动机、恒等推导、在序列建模
       中的实现、以及如何引出自回归训练的并行化与串行推理矛盾。

       问题 0 · 计算多变量同时发生的概率为何困难？
       │
       ├── 设 X₁, X₂, ..., X_T 为离散变量，每个有 V 种取值。
       │   联合分布需要为 V^T 种组合分别指定概率，存储与估计均不可行。
       │
       ├── 现实任务（如语言建模）中，常需根据已有上下文预测下一个
       │   词，或计算整个序列的似然。直接使用联合分布表格无法处理。
       │
       └── 根本需求：需要一种方法，将高维问题拆解为多个低维问题，
           且不丢失任何概率信息。
           ↓
           链式法则提供严格向下分解的手段。

       问题 1 · 如何无损地将联合分布写为条件分布的乘积？
       │
       ├── 两步变量的乘法法则已知：
       │       P(A, B) = P(A) P(B|A)  （若 A, B 为事件）
       │
       ├── 推广到 T 个变量，只需反复应用乘法法则：
       │       P(X₁, X₂, X₃) = P(X₁) P(X₂, X₃ | X₁)
       │                      = P(X₁) P(X₂|X₁) P(X₃|X₁, X₂)
       │   一般形式：
       │       P(X₁, ..., X_T) = P(X₁) ∏_{t=2}^T P(X_t | X₁, ..., X_{t-1})
       │       或记为 P(X₁, ..., X_T) = ∏_{t=1}^T P(X_t | X_{<t})
       │   其中 X_{<t} ≡ (X₁, ..., X_{t-1})。
       │
       ├── 恒等等价：
       │   该分解未引入任何假设，严格等于原始的联合分布。它将
       │   V^T 规模的分布表替换为一组条件分布，每个条件分布仅
       │   需对下一变量给出概率，规模 V（但条件历史呈指数增长，
       │   实际仍需进一步参数化）。
       │
       └── 这立即引出下一个问题：如何对每个条件概率进行建模，
           以克服“历史长度 t 增长时条件表复杂度同样爆炸”的难题？

       问题 2 · 如何采用参数化模型近似每个条件项？
       │
       ├── 子概念：自回归假设与函数近似
       │   - 使用一个带参数 θ 的函数 f_θ，以历史 X_{<t} 为输入，
       │     输出对 X_t 的概率分布。
       │       P_θ(X_t | X_{<t}) = f_θ(X_{<t})[X_t]
       │   - f_θ 由神经网络（如 Transformer）实现，θ 通过训练
       │     全部时间步共享。
       │   - 由于链式法则的条件历史长度可变，模型必须能处理
       │     不定长输入并保留因果顺序。
       │
       ├── 由此得到序列的模型似然：
       │       P_θ(X) = ∏_{t=1}^T f_θ(x_t | x_{<t})
       │   最大化似然等价于最小化负对数似然：
       │       L(θ) = - Σ_{t=1}^T log f_θ(x_t | x_{<t})
       │   每个时间步是一个分类任务（预测下一 token）。
       │
       └── 训练时，需要为每个位置 t 计算 f_θ(x_t | x_{<t})。
           如果每步单独计算，需 T 次模型前向，极低效。
           因此关键问题是：能否一趟前向计算所有位置的条件概率？

       问题 3 · 如何在一次前向中并行计算所有条件项？
       │
       ├── 答案：因果自注意力（Causal Attention）与教师强制
       │   - 在一次前向中，模型输入完整序列 X (x₁,…,x_T)。
       │   - 注意力层使用上三角掩码，保证位置 t 的表示 h_t 只
       │     能融合 1..t 的信息，无法看到未来 t+1..T。
       │   - 因此，h_t 正是对历史 X_{<t} 的有效编码，满足了
       │     链式法则的因果约束。
       │   - 输出层用 h_t 预测 x_t 的条件分布，损失函数在所有
       │     位置上叠加（教师强制：使用真实 x_t 而非模型预测作为
       │     下一位置的输入，训练时无需串行）。
       │
       ├── 并行训练效率：
       │       一次 forward-backward 完成整条序列的训练，
       │       复杂度为 O(T² d)（注意力）+ O(T d²)（线性层），
       │       完全消除了 T 次串行调用的成本。
       │
       └── 然而，生成时情况不同：生成第 t+1 步必须使用模型采样
           得到的 x_t，无法提前获知未来 token，因此必须串行迭代。
           这一训练与推理的分离，使推理效率成为核心瓶颈。

       问题 4 · 链式法则如何引发现代推理系统的设计？
       │
       ├── 推理时的串行约束：
       │   要为序列生成下一个 token，必须先有完整前缀。
       │   每一步前向只产出一个 token，连续 T 步生成需要 T 次
       │   依次执行。
       │
       ├── KV 缓存的必要性：
       │   链式法则要求每步纳入所有历史，若每步重算历史 Key/Value
       │   将带来 O(T² d²) 的投影开销。缓存 K,V 是链式法则下唯一
       │   可行的加速手段（见 kv-cache(7)）。
       │
       ├── 批次调度的弹性：
       │   不同请求处于自回归链的不同位置，单次迭代内需要混合
       │   prefill 与 decode，这推动了 Continuous Batching 与
       │   迭代级调度（见 continuous-batching(7)）。
       │
       └── 因此，链式法则不仅是一个概率恒等式，更是整个 LLM 
           推理栈推理走向统一的数学约束，它定义了顺序依赖，从而
           决定了内存布局与调度边界。

结论
       链式法则以 P(X) = ∏ P(X_t | X_{<t}) 将高维联合概率解耦为
       逐步条件预测。它在数学上无损，在计算上通过参数化模型与因果
       掩码实现高度并行训练。同时，它在生成时强制串行，引出了缓存、
       批处理、分页等一系列推理架构的基石设计。理解链式法则，即是
       理解自回归模型为什么“这样训练，那样推理”。

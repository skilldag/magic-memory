LIKELIHOOD(7)               统计推断基础                   LIKELIHOOD(7)

名称
       likelihood — 给定模型参数时观测到已发生数据的合理性度量，是对
                   参数信任度的评分函数而非概率分布

概述
       Likelihood（似然）是统计推断的核心概念，它将“参数值到底有多
       吻合观测数据”量化。它不回答“参数有多大概率”，而是回答“如果
       参数是这个值，我们看到这组数据的概率有多大”。此概念直接导出
       最大似然估计、负对数似然损失，成为机器学习训练的数学根基。

描述
       本手册以层层问题推导，从概率与似然的本质区别出发，逐步展开似然
       的数学形式、计算优化以及其在深度学习中的角色。

       问题 0 · 概率与似然有何根本不同？
       │
       ├── 概率（Probability）：
       │   - 参数固定（已知的分布，如一枚公平硬币 p=0.5），数据变化。
       │   - 问题：“如果硬币是公平的，连续扔出3次正面的概率是多少？”
       │   - 所有可能结果上的概率（求和/积分）为 1。
       │
       ├── 似然（Likelihood）：
       │   - 数据固定（已观测到的结果，如“扔了3次，全是正面”），参数变化。
       │   - 问题：“既然看到3次正面，那么硬币正面概率 p 等于多少最合理？”
       │   - 它不是参数的概率分布，对参数积分通常不等于 1。
       │
       ├── 形式定义（离散情况）：
       │   概率质量函数 P(X = x | θ)   ← θ 固定，x 可变
       │   似然函数      L(θ | x) = P(X = x | θ)  ← x 固定，θ 可变
       │   二者数值相等，但自变量不同，含义迥异。
       │
       └── 似然因此成为“参数相对于数据的评分函数”，值越大，
           表示该参数值越能让观测数据“显得正常”。这自然引出：
           如何找到让数据最“正常”的参数？

       问题 1 · 如何用似然寻找最优参数？
       │
       ├── 直觉：在所有可能的 θ 中，选择使 L(θ | D) 最大的那个。
       │   → 最大似然估计（Maximum Likelihood Estimation, MLE）
       │        θ̂ = argmax_θ L(θ | D)
       │
       ├── 独立同分布数据下，总似然为各数据点似然之积：
       │        L(θ | D) = ∏_{i=1}^N P(x_i | θ)
       │   （因为独立事件的联合概率是各概率的乘积）
       │
       ├── 统计性质（在大样本下）：
       │   - 一致性：θ̂ 会收敛到真实参数值。
       │   - 渐近有效：θ̂ 的方差达到理论下界（Cramér–Rao），即最充分利用数据。
       │   - 这些优良性质使得 MLE 成为参数估计的黄金标准。
       │
       └── 但乘积形式在数据量大时导致严重下溢，需要数值优化上的转化。
           → 引出对数似然。

       问题 2 · 如何处理大量小于1的似然值乘积？
       │
       ├── 直接连乘造成浮点下溢：0.5^1000 ≈ 10^{-301}，超出 float64 范围。
       │
       ├── 取对数变换：log 是单调递增函数，最大化 L 等价于最大化 log L。
       │   对数似然（log-likelihood）：
       │        ℓ(θ) = log L(θ | D) = Σ_{i=1}^N log P(x_i | θ)
       │   乘积变求和，数值稳定。且和式求导方便。
       │
       ├── 机器学习习惯：最小化损失。故定义负对数似然损失（NLL）：
       │        NLL(θ) = -ℓ(θ) = - Σ_{i} log P(x_i | θ)
       │   最大化似然 ⇔ 最小化 NLL。
       │   对于分类/生成任务，它等价于交叉熵损失。
       │
       └── 由此，似然从一个哲学概念变为可计算、可优化的训练目标。
           但对序列数据（文本），P(x_i | θ) 本身是整句话的概率，
           这如何计算？→ 需继续分解。

       问题 3 · 似然在序列模型（如 LLM）中如何计算？
       │
       ├── 序列的概率通过链式法则分解为条件概率之积：
       │        P(x₁, ..., x_T | θ) = ∏_{t=1}^T P(x_t | x_{<t}, θ)
       │   （见 chain-rule(7)）
       │
       ├── 因此，序列的似然函数为：
       │        L(θ | x) = ∏_{t=1}^T P_θ(x_t | x_{<t})
       │   每个因子是模型在位置 t 对下一个 token 的预测概率。
       │
       ├── 训练时，用因果注意力一次前向计算所有位置的对数似然：
       │        ℓ(θ) = Σ_{t=1}^T log P_θ(x_t | x_{<t})
       │   损失函数的梯度反向传播更新 θ，不断增大 ℓ(θ)（或减小 NLL）。
       │
       └── 推理时，模型迭代地基于已生成序列选择下一 token，每一步
           都依赖之前已缓存的状态——这正是自回归解码（autoregressive-decoding(7)）
           的机制，其底层的评分逻辑始终是“当前参数下哪个 token 似然最大”。

       问题 4 · 似然方法相比其他准则有何优势？
       │
       ├── 统一性：无论模型是线性回归（MSE 损失可导出为高斯似然的 NLL）、
       │   Logistic 回归（交叉熵）还是 Transformer（因果语言模型），
       │   它们都在最大化某种似然。这让不同模型能在同一理论框架下比较。
       │
       ├── 信息论解释：最小化 NLL 等价于最小化模型分布与真实数据分布
       │   之间的 KL 散度，因而直接驱动模型逼近真实分布。
       │
       ├── 概率校准：优化似然的模型会输出校准的预测概率，而不仅仅是
       │   硬分类，这对需要置信度评估的任务至关重要。
       │
       └── 由此，似然贯穿了从基础统计推断到前沿大模型训练的全栈，
           始终扮演“模型与数据的适配度函数”这一核心角色。

结论
       Likelihood 翻转了概率的观测视角，将固定数据作为条件、参数作为
       变量，为参数估计提供了自然评分。通过最大似然及数值稳定的 NLL
       转化，它成为所有监督生成模型训练的统一损失。在序列生成领域，
       结合链式法则与自回归分解，似然定义了语言模型每一步预测的目标，
       并最终塑造了现代 LLM 的学习与推理范式。

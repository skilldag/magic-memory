NEGATIVE-LOG-LIKELIHOOD(7)  统计机器学习                NEGATIVE-LOG-LIKELIHOOD(7)

名称
       negative-log-likelihood — 通过等价转化，将最大似然估计变为可数值
                                 稳定、并行优化的凸损失函数

概述
       最小化负对数似然（min NLL）是最大似然估计（MLE）的计算翻版。将
       乘积形式的似然取负对数后，优化目标变成求和，避免了浮点下溢，且
       其梯度自然导向最陡下降方向。在 Transformer 训练中，NLL 即为交叉
       熵损失，驱动模型从数据中学习条件概率分布。

描述
       本手册沿层层问题推导，从“寻找最可能参数”出发，逐步解释为何需要
       对数、为何取负，以及如何最终变为交叉熵。

       问题 0 · 如何找到能“最好地解释”观测数据的模型参数？
       │
       ├── 给定独立同分布样本 D = {x⁽¹⁾, ..., x⁽ᴺ⁾} 和参数化概率模型
       │    P_θ(x)，希望找到使 D 出现概率最大的 θ。
       │    → 此即最大似然估计 (MLE)。
       │
       ├── 似然函数：
       │        L(θ) = P_θ(D) = ∏_{i=1}^N P_θ(x⁽ⁱ⁾)
       │    或对于序列（自回归分解，见 chain-rule(7)）：
       │        L(θ) = ∏_{i} ∏_{t} P_θ(xₜ | x_{<t})
       │
       └── 因乘积个数极多且每个概率 ≤1，连乘后数值向零急剧下溢，
           无法在有限精度浮点下表示。必须转换。

       问题 1 · 如何安全地处理大量概率的乘积？
       │
       ├── 取对数：利用单调递增性质，最大化似然等价于最大化对数似然。
       │        log L(θ) = Σ_{i=1}^N log P_θ(x⁽ⁱ⁾)
       │   - 乘积变求和，数值范围可控。
       │   - 对数似然为负值（或非正），总和仍在浮点可表示区间。
       │
       ├── 机器学习习惯：通常最小化目标，因此取负得到损失函数。
       │        损失 L_NLL(θ) = - log L(θ) = - Σ_{i} log P_θ(x⁽ⁱ⁾)
       │   最大化似然 ⇔ 最小化负对数似然 (NLL)。
       │
       └── NLL 常被平均以尺度无关：
                 ℓ(θ) = - (1/N) Σ_{i} log P_θ(x⁽ⁱ⁾)
            这就是交叉熵损失在分类/生成任务中的标准形式。

       问题 2 · 最小化 NLL 如何对应“缩小模型分布与真实分布的差异”？
       │
       ├── 信息论视角：
       │   真实数据分布记为 P_data，模型分布为 P_θ。
       │   交叉熵 H(P_data, P_θ) = - E_{x~P_data}[ log P_θ(x) ]
       │   当使用数据经验分布近似 P_data 时，交叉熵等于 NLL 的平均。
       │   由于 H(P_data, P_θ) = H(P_data) + KL(P_data || P_θ)
       │   而 H(P_data) 是常数，最小化 NLL 等价于最小化 KL 散度，
       │   即迫使模型分布逼近真实数据分布。
       │
       ├── 梯度特性：
       │        ∇_θ ℓ(θ) = - (1/N) Σ_{i} ∇_θ log P_θ(x⁽ⁱ⁾)
       │   该梯度指使概率提升最快的方向。更新 θ := θ - η·∇_θ ℓ(θ)
       │   等同于降低 surprise（提高模型对数据的接纳度）。
       │
       └── 引出问题：对于序列模型（如 Transformer），如何在一次前向
           中计算整个序列所有位置的 NLL？

       问题 3 · 序列模型如何一次性计算多位置的 NLL 损失？
       │
       ├── 序列的 NLL 是所有时间步条件对数概率的负和：
       │        L_NLL = - Σ_{t=1}^T log P_θ(x_t | x_{<t})
       │   每个位置 t 的 log P_θ(x_t | x_{<t}) 由模型最后一个线性层
       │   的 log-softmax 提供。
       │
       ├── 借助教师强制（Teacher Forcing）和因果掩码：
       │   - 一次前向输入完整序列 [x₁,…,x_T]。
       │   - 因果注意力保证位置 t 仅能看到 1..t，因而其输出隐状态
       │     正是对 x_{<t} 的有效编码。
       │   - 对每个位置 t（1≤t≤T-1，用于预测下一个）计算交叉熵：
       │         loss = Σ_{t=1}^{T-1} CrossEntropy( logits[t], target=x_{t+1} )
       │   - 通常忽略最后位置的预测（无目标），或使用特殊结束符。
       │
       ├── 并行化优势：
       │   一次 forward-backward 得到所有位置的梯度，无需串行 T 次。
       │   时间复杂度 O(T² d + T d²)，在 GPU 上被高度并行化。
       │
       └── 由此引出一致性：负对数似然是自回归模型训练的唯一损失函数，
           其简洁性与链式法则完美适配，而推理时的串行生成则共享同一
           套条件概率但需逐步采样（见 autoregressive-decoding(7)）。

       问题 4 · 为何说 NLL 是“严格正确”的损失函数？
       │
       ├── 一致性：如果模型族包含真实分布且数据量无穷，MLE（即
       │   最小化 NLL）可渐近恢复真实参数（统计一致性）。
       │
       ├── 校准性：优化 NLL 鼓励模型输出准确的概率，而不仅仅是
       │   选择最高分的类别。这使模型具备良好校准，可量化不确定性。
       │
       ├── 与其他损失的对比：
       │   - 0-1 损失仅关注是否正确，不要求概率校准。
       │   - 均方误差（MSE）在分类中可能收敛慢，梯度平坦。
       │   - NLL / 交叉熵提供对数尺度梯度，且与信息论意义对齐。
       │
       └── 因此，几乎所有基于神经网络的生成模型（语言、语音、图像）
           都采用 NLL 或其变体（如 VAE 的 ELBO 也基于对数似然下界）。

结论
       最小化负对数似然将寻找“最可能生成数据”的参数这一统计目标，
       转化为数值稳定的求和损失。它是最大似然的学习等价，通过信息
       论桥接，等价于最小化 KL 散度与交叉熵。其序列形式天然与自回
       归建模结合，一次因果前向即可获得整条序列的训练信号，成为
       Transformer 预训练的唯一核心损失。

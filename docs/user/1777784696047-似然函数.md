LIKELIHOOD-FUNCTION(7)       统计推断基础              LIKELIHOOD-FUNCTION(7)

名称
       likelihood-function — 以参数为自变量、数据为条件的模型可信度函数

概述
       似然函数 L(θ|D) 将参数 θ 映射为“在该参数下观测到数据 D 的概率”，
       是将模型参数与数据拟合度连接起来的数学桥梁。它不是参数的概率
       分布，而是参数优劣的评分函数，直接催生了最大似然估计与负对数
       似然损失等训练准则。

描述
       本手册沿问题推导链解构似然函数的定义、与概率的区别及如何演化
       为优化目标，使用树状缩进与简明公式。

       问题 0 · 给定数据，如何量化“某个参数值有多合理”？
       │
       ├── 情境：拥有一个参数化概率模型 P(X | θ)，例如正态分布由
       │   均值和方差参数化，或语言模型由神经网络权重 θ 参数化。
       │   观测到一组数据 D = {x₁, x₂, ..., x_N}。
       │
       ├── 直觉：若在 θ₁ 下 D 出现的概率远大于在 θ₂ 下的概率，
       │   则 θ₁ 是更“好”的解释。因此，自然的度量是：
       │       “数据在给定参数下的出现概率”
       │
       ├── 定义（似然函数）：
       │        L(θ | D) = P(D | θ)
       │   对于独立同分布数据，可分解为乘积：
       │        L(θ | D) = ∏_{i=1}^N P(x_i | θ)
       │   注意：虽然右侧是概率（密度），但 L(θ|D) 被视作 θ 的函数，
       │   数据 D 固定。它不是 θ 的概率分布（对 θ 积分不为 1）。
       │
       └── 似然函数为每个候选参数给出一个分值，引出自然问题：
           如何找到使似然最大的参数？ → 最大似然估计 (MLE)。

       问题 1 · 如何利用似然函数选取最优参数？
       │
       ├── 子概念：最大似然估计 (Maximum Likelihood Estimation)
       │   - 寻找使似然函数最大的参数值：
       │         θ̂_MLE = argmax_θ L(θ | D)
       │   - 直观：选那个让已发生事件“最不显得意外”的参数。
       │   - 当样本量趋于无穷时，MLE 具有一致性（收敛到真值）和
       │     渐近有效（方差达到 Cramér–Rao 下界）。
       │
       ├── 计算挑战：乘积形式 L(θ) 包含极多小于 1 的因子，
       │   直接连乘会迅速下溢到浮点零，且求导复杂。
       │
       └── 解决之道：取对数转换为求和。
           → 引出对数似然与负对数似然损失。

       问题 2 · 如何将乘积变为求和以稳定计算？
       │
       ├── 对数似然 (Log-Likelihood)：
       │        ℓ(θ) = log L(θ | D) = Σ_{i=1}^N log P(x_i | θ)
       │   - 乘积变求和，数值范围可控。
       │   - 因对数函数单调递增，最大化 L(θ) 等价于最大化 ℓ(θ)。
       │
       ├── 负对数似然 (Negative Log-Likelihood, NLL)：
       │   优化惯例为最小化，故取负：
       │        NLL(θ) = -ℓ(θ) = - Σ_{i} log P(x_i | θ)
       │   最大化似然 ⇔ 最小化 NLL。
       │   NLL 在许多框架中即交叉熵损失（见 negative-log-likelihood(7)）。
       │
       └── 此时，似然函数已从“参数评分器”转化为“损失函数”，
           模型训练即为不断降低 NLL 的过程。但序列模型（如文本）的
           P(x|θ) 如何定义？ → 需分解为条件分布。

       问题 3 · 对于序列数据，似然函数怎样分解？
       │
       ├── 序列 x = (x₁, ..., x_T) 的联合概率可由链式法则分解：
       │        P(x | θ) = ∏_{t=1}^T P(x_t | x_{<t}, θ)
       │   （见 chain-rule(7)）
       │
       ├── 因此，序列的似然函数为：
       │        L(θ | x) = ∏_{t=1}^T P_θ(x_t | x_{<t})
       │   对数似然：
       │        ℓ(θ) = Σ_{t=1}^T log P_θ(x_t | x_{<t})
       │   负对数似然：
       │        NLL(θ) = - Σ_{t=1}^T log P_θ(x_t | x_{<t})
       │
       ├── 训练时，使用教师强制（Teacher Forcing）和因果掩码，
       │   一次前向可并行计算所有位置的条件概率，并累加为总损失。
       │   这使极大似然估计成为 Transformer 预训练的唯一目标。
       │
       └── 似然函数贯穿统计建模与深度学习：无论模型是线性回归、
           逻辑回归还是千亿参数大模型，训练本质均为最大化（对数）似然。

       问题 4 · 似然函数与概率有何本质区别？
       │
       ├── 概率：参数固定，数据变化。例：θ 给定时，不同数据 D 的
       │   分布 P(D | θ)。所有可能 D 的概率（或积分）之和为 1。
       │
       ├── 似然：数据固定，参数变化。L(θ | D) 是 θ 的函数，衡量
       │   不同 θ 解释固定 D 的相对可信度。其对 θ 的积分通常不为 1。
       │   它不是 θ 的概率密度，不可直接用于贝叶斯推断（需先验）。
       │
       └── 这一区分是频率学派与贝叶斯学派的分野：频率学派用似然
           进行点估计（MLE），贝叶斯学派将其与先验结合得到后验
           P(θ | D) ∝ L(θ | D) P(θ)。

结论
       似然函数是给定数据后参数的评分函数，其将模型参数与数据拟合度
       量化为一数值。通过最大化似然（或最小化负对数似然），模型被
       驱向与观测数据最一致的参数。结合链式法则，它自然支撑了自回归
       序列模型的训练，成为现代生成式 AI 的统一优化框架。

AUTOREGRESSIVE(7)            机器学习基础               AUTOREGRESSIVE(7)

名称
       autoregressive — 将联合分布分解为条件分布之积的序列建模范式

概述
       自回归模型假设序列的当前值仅依赖于自身历史值，由此将复杂
       联合分布转化为逐步条件预测。此范式统一了从线性时间序列到
       Transformer 语言模型的概率基座，是生成式 AI 的数学根源。

描述
       本手册以层层递推的方式构建自回归的数学定义、训练方法、生成
       机制以及其在深度学习中的实现约束。

       问题 0 · 如何定义可变长度序列的概率分布？
       │
       ├── 挑战：序列 x = (x₁, x₂, ..., x_T) 长度 T 可变，
       │   直接定义 P(x) 需要枚举指数级多的可能序列，不可行。
       │
       ├── 核心分解（概率链式法则）：
       │        P(x) = P(x₁) · P(x₂|x₁) · P(x₃|x₂,x₁) · ... 
       │             = Π_{t=1}^T P(x_t | x_{<t})
       │   其中 x_{<t} 表示前 t-1 个元素。
       │   这一分解不损失任何信息，精确成立。
       │
       ├── 自回归假设：
       │       每个条件分布 P(x_t | x_{<t}) 仅依赖于前序元素，
       │       且通常共享同一参数化模型函数 f_θ。
       │           P(x_t | x_{<t}) ≈ f_θ(x_{<t})[x_t]
       │   模型因此具有时间因果结构：未来不影响过去，过去决定未来。
       │
       └── 由此，复杂的全局分布学习转化为逐步预测的回归任务，
           每个时间步输出对下一个值的分布预测。

       问题 1 · 如何使用神经网络实现这样的条件模型？
       │
       ├── 序列输入：将历史 x_{<t} 编码为固定维度的上下文表征 h_t。
       │   - 经典方法：RNN/LSTM 逐步更新隐藏状态。
       │   - 现代方法：Transformer 的自注意力，通过因果掩码确保
       │     位置 t 只能关注 1..t-1，从而并行计算所有位置的 h_t。
       │
       ├── 输出层：h_t 经线性变换 + softmax 返回词表 V 上的概率分布：
       │        P_θ(x_t | x_{<t}) = softmax(W h_t)
       │
       ├── 参数量：θ 包含嵌入矩阵、注意力权重、FFN 等，规模可达千亿。
       │   自回归框架使庞大的模型能够以“预测下一个 token”这一统一
       │   目标进行训练。
       │
       └── 该框架极其通用：任何序列（文本、音频、图像块、代码）只
           要能离散化为 token，均可训练自回归生成模型。

       问题 2 · 自回归模型如何高效训练？
       │
       ├── 训练目标：最大化完整序列的似然，等价于最小化
       │        L(θ) = -Σ_{t=1}^T log P_θ(x_t | x_{<t})
       │   即交叉熵损失在每个时间步的平均。
       │
       ├── 教师强制（Teacher Forcing）：
       │   - 训练时，无论模型上一时刻预测的对错，下一时刻的输入
       │     始终使用真实 token x_t（来自数据集），而非模型自己的输出。
       │   - 由此，所有时间步的条件分布可一次性并行计算，无需串行。
       │   - 因果自注意力（Causal Self-Attention）通过上三角掩码
       │     确保位置 t 不可见未来，从而使一次前向直接算出所有位置的
       │     h_t 和 loss，实现 O(1) 次模型调用完成全序列训练。
       │
       ├── 并行训练方程：
       │       对一条序列 X ∈ R^{T×d_model}，单次 forward 得到
       │       logits ∈ R^{T×V}，与真实标签 Y[1..T] 计算交叉熵。
       │       梯度通过时间反向传播（BPTT）或自动求导传递。
       │
       └── 大规模预训练的自回归目标（如 GPT 系列）是扩展定律的基石，
           其成功凸显了自回归范式的数据效率与稳定性。

       问题 3 · 训练完成后，如何生成新序列？
       │
       ├── 生成过程（自回归解码）：
       │   - 给出起始 prompt（或单个 <bos> token）。
       │   - 重复：
       │         1. 将已有序列输入模型，获取最后一位置的 logits。
       │         2. 从 softmax(logits) 中采样（或贪婪选择）下一个 token。
       │         3. 将该 token 拼接到序列末尾。
       │   - 直到生成 <eos> 或达到最大长度。
       │   - 详见 autoregressive-decoding(7)。
       │
       ├── 串行依赖：
       │   由于每步输出依赖于包含前一步输出的完整历史，生成无法并行。
       │   这是自回归模型推理的根本约束，也是 KV 缓存、批处理等
       │   所有推理加速技术的出发点。
       │
       └── 训练与生成的差异：
           训练：并行输入全序列，一次获得所有 loss（教师强制）。
           生成：串行迭代，每步进行一次模型前向，历史由缓存携带。

       问题 4 · 自回归假设带来了哪些固有限制？
       │
       ├── (A) 单向上下文：标准的自回归仅使用左侧历史，无法自然地
       │    融入双向语境（这由 Masked LM 如 BERT 解决，但失去生成能力）。
       │    → 部分模型引入 Prefix-LM 或 Encoder-Decoder 折中。
       │
       ├── (B) 误差累积：训练时使用真实历史，生成时使用预测历史。
       │    一个错误可能诱使后续步进入训练未见的分布，导致质量滚降。
       │    → 解决方法：Scheduled Sampling、强化学习微调（RLHF）。
       │
       ├── (C) 推理延迟与显存：串行生成使长序列延迟高，且 KV 缓存
       │    随长度线性膨胀。
       │    → 系统优化：PagedAttention、FlashAttention、量化等
       │      （见 pageattention(7), flash-attention(7)）。
       │
       └── 尽管存在这些挑战，自回归模型因其数学简洁性、训练稳定性
           及强大的扩展性能，仍是当今生成式 AI 的绝对主流范式。

结论
       自回归将序列概率分解为逐 token 条件预测，以链式法则为根基，
       以因果掩码实现高效并行训练，以串行解码进行生成。它既是
       Transformer 语言模型的理论来源，也是其推理系统设计的物理约束。
       理解这一范式，即握住了从 GPT 到 vLLM 整个技术栈的起点。

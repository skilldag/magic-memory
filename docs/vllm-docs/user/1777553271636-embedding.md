# EMBEDDING(7)

## NAME

embedding — 密集向量表示的核心原理

## SYNOPSIS

本文从离散符号的表示困境出发，以“问题 → 局部解答 → 引出下一问题”的推导方式，阐述嵌入（embedding）如何从分布假说、语言建模与噪声对比估计中涌现为低维、稠密且蕴含语义的向量。

## DESCRIPTION

问题 1————如何将离散符号（如词）输入数值模型？

- 方案：独热编码 (One-Hot)  
用基向量标识每个词：  
$\mathbf{x} \in \{0,1\}^{|V|},\quad \sum_{i=1}^{|V|} x_i = 1,\quad x_k=1 \leftrightarrow \text{词 }k$
- 缺陷：  
· 维度灾难：|V| 通常 > 10^5，向量极度稀疏。  
· 语义真空：任意不同词的独热向量正交，  
$\mathbf{x}_i^\top \mathbf{x}_j = 0 \quad (i \neq j),$  
无法表达相似度。
- ⇒ 引出问题：能否将符号映射到低维连续空间，使相似度可度量？

问题 2————如何构造低维、可度量相似度的向量？

- 子概念：分布式表示与嵌入矩阵  
设嵌入维度 d ≪ |V|，嵌入矩阵 $\mathbf{W} \in \mathbb{R}^{d \times |V|}$。  
查表操作（lookup）等价于线性投影：  
$\mathbf{e} = \mathbf{W} \mathbf{x} \quad \text{即选取 } \mathbf{W} \text{ 的第 } k \text{ 列作为词 } k \text{ 的向量。}$
- 相似度度量：余弦相似度  
$\mathrm{sim}(\mathbf{e}_i, \mathbf{e}_j) = \frac{\mathbf{e}_i^\top \mathbf{e}_j}{\|\mathbf{e}_i\|\ \|\mathbf{e}_j\|}$
- 当前困境：$\mathbf{W}$ 元素随机，向量不含语义。需要目标引导学习。
- ⇒ 引出问题：依据什么准则学习 $\mathbf{W}$，才能让向量携带语义信息？

问题 3————语义的学习准则从何处来？

- 基石：分布假说 (Distributional Hypothesis)  
“一个词的含义可由其上下文决定” (Harris, 1954; Firth, 1957)。  
因此，使向量能够预测其上下文，语义便会内化于向量中。
- 数学模型：Skip‑gram 语言建模  
给定中心词 $w_t$，最大化预测其窗口内上下文词 $w_{t+j}$ 的对数似然：  
$\mathcal{J} = \frac{1}{T} \sum_{t=1}^T \sum_{-c \le j \le c,\, j \ne 0} \log P(w_{t+j} \mid w_t)$  
条件概率由向量内积 softmax 定义（$v$ 为中心向量，$u$ 为上下文向量）：  
$P(w_o \mid w_i) = \frac{\exp(\mathbf{u}_{w_o}^\top \mathbf{v}_{w_i})}{\sum_{w \in V} \exp(\mathbf{u}_w^\top \mathbf{v}_{w_i})}$
- 计算瓶颈：分母需遍历整个词汇表，O(|V|) 成本不可承受。
- ⇒ 引出问题：如何高效近似 softmax，使大规模学习可行？

问题 4————如何高效近似全词汇 softmax？

- 解决过程：噪声对比估计与负采样 (Negative Sampling)  
将多分类转化为二分类——区分真实上下文对与噪声采样对。  
对每一个正样本 $(\mathbf{v}_{w_i}, \mathbf{u}_{w_o})$，从噪声分布 $P_n(w)$ 中抽取 $K$ 个负样 本词 $w_k$：  
$\mathcal{L}_{\text{NS}} = \log \sigma(\mathbf{u}_{w_o}^\top \mathbf{v}_{w_i}) + \sum_{k=1}^K \mathbb{E}_{w_k \sim P_n} \left[ \log \sigma(-\mathbf{u}_{w_k}^\top \mathbf{v}_{w_i}) \right]$  
其中 $\sigma(z) = 1/(1+e^{-z})$。该目标只需 $O(K)$ 计算，$K \ll |V|$，可通过随机梯度下降高效优化。
- 结果：迭代收敛后，中心向量 $\mathbf{v}_w$（或与上下文向量的组合）即为词嵌入（word embedding），具备 **语义线性结构**：  
$\mathbf{v}_{\text{king}} - \mathbf{v}_{\text{man}} + \mathbf{v}_{\text{woman}} \approx \mathbf{v}_{\text{queen}}$
- 局部解答的局限：上述 $\mathbf{v}_w$ 是静态向量，无法区分“苹果很好吃”与“苹果发布了新手机”中的一词多义。
- ⇒ 引出后续问题：如何让同一个词的向量根据上下文动态变化？——引出上下文感知嵌入（ELMo, BERT 等）。

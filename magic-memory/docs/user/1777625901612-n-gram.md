NAME
  序列概率估计 — 给任意一个词序列打「合理性」分数的计算方法

SYNOPSIS
  输入：词序列 w₁, w₂, ..., w_T
  输出：[0,1] 之间的概率 P(w₁:T)，表示这句话有多「像人话」

DESCRIPTION
  序列概率估计要回答一个很根本的问题：**给定一个句子，它作为自然语言
  出现的可能性是多少？** 本手册由该问题出发，顺着困难→解决→新困难的
  推导链，给出从理论分解到工程实践的核心原理。

  ● 问题 1：一句话很长，没法直接数它在语料里出现几次，怎么算概率？
    ├─ 子概念：语言模型是一个概率分布
    │  它必须给每一个可能的词序列一个概率，且所有序列的概率和为 1。
    │  这能让我们定量比较：“猫吃鱼”比“鱼吃猫”更像人话。
    ├─ 解决过程：不要一次数完整句，用条件概率拆开
    │  采用**链式法则**，把联合概率变成一步步预测概率的乘积：
    │    P(我 爱 学习) = P(我) × P(爱|我) × P(学习|我 爱)
    │  通式：
    │    P(w₁:T) = ∏_{t=1}^T P(w_t | w₁:t−1)
    │  现在只需关心“给定历史，下一个词的概率”，但历史越来越长，
    │  条件 w₁:t−1 有 |V|^{t-1} 种可能，再多数据也统计不出来。
    └─ 引出问题 2：历史太长，如何缩短它，同时保持预测靠谱？

  ● 问题 2：如何把无限长的历史压缩成固定长度的上下文？
    ├─ 子概念：n-1 阶马尔可夫假设（N-gram 模型）
    │  假设一个词的出现只依赖它前面最近 n−1 个词，忽略更早的历史。
    │  这就把历史窗口固定住了，参数数量从指数级降为多项式级。
    ├─ 解决过程：
    │  1. 选择 n 的大小，比如 n=2 (bigram) 或 n=3 (trigram)。
    │  2. 用截断历史近似条件概率：
    │        P(w_t | w₁:t−1) ≈ P(w_t | w_{t−n+1}^{t−1})
    │  3. 序列概率近似为：
    │        P(w₁:T) ≈ ∏_{t=1}^T P(w_t | w_{t−n+1}^{t−1})
    │  4. 例如 bigram 里，P(学习|我 爱) ≈ P(学习|爱)，
    │     历史只剩一个词，统计就变得可行。
    └─ 引出问题 3：这些截断后的条件概率如何从数据里算出来？

  ● 问题 3：怎么把见过的 n-gram 频次变成概率值？
    ├─ 子概念：最大似然估计（MLE）
    │  直觉：用历史 h 后面出现词 w_t 的次数，除以历史 h 本身的总次数。
    │  公式：
    │    P_MLE(w_t | h) = C(h, w_t) / C(h)
    │  这能让训练数据的整体概率达到最大，是直接且一致的方法。
    ├─ 解决过程：
    │  1. 从语料中切出所有 n-gram，统计每个 (历史, 下一个词) 的频次。
    │  2. 按上述除法得到条件概率。
    │  3. 严重缺陷：如果某个 (h, w_t) 从未出现过，C(h,w_t)=0，
    │     概率就是 0。只要句中有一个这样的组合，整个句子的概率就归零，
    │     哪怕其余部分再合理也没用，即“零概率灾难”。
    └─ 引出问题 4：如何给未见过的组合也留点概率？

  ● 问题 4：如何把一部分概率“匀”给没见过的事件？
    ├─ 子概念：平滑（Smoothing）与回退（Back-off）
    │  核心思想：从高频的 n-gram 身上“扣下”一点点概率，重新分给
    │  低频或零频的 n-gram。高阶统计不够用时就退回到低阶 n-gram。
    ├─ 解决过程（几种经典手法）：
    │  1. 加法（Lidstone）平滑：
    │        所有可能的 (h,w) 计数先加上一个小常数 δ (如 0.5)，
    │        再归一化。简单但效果一般。
    │  2. 回退（Katz Back-off）：
    │        若 C(h,w_t) > 0，用打了折扣的 P_disc(h,w_t)；
    │        否则用缩放因子 α(h) 乘上 shortening 历史的概率。
    │  3. 插值（Jelinek-Mercer）：
    │        不同阶模型加权混合，权重由数据自动学习。
    │  4. Kneser-Ney 平滑：
    │        回退时不用“w 有多常见”，而用“w 能承接多少种不同的
    │        上文历史”，完美适配语言规律，是公认最优的 n-gram 平滑。
    │  平滑后所有词都有正概率，句子概率再也不会直接塌为 0。
    └─ 引出问题 5：模型建好了，怎么判断它好不好？

  ● 问题 5：如何评价一个序列概率估计模型的质量？
    ├─ 子概念：困惑度（Perplexity, PPL）
    │  基于信息论的交叉熵，衡量模型对一段测试文本的“平均惊讶度”。
    │  困惑度等于模型看到的平均每词等效分支数，越小越好。
    ├─ 解决过程：
    │  1. 用测试集 w₁:M 计算模型给的总概率 P(D)。
    │  2. 求平均交叉熵：
    │        H = − (1/M) log₂ P(D)
    │  3. 计算困惑度：
    │        PPL = 2^H = P(D)^{−1/M}
    │  4. 若 PPL=50，意味着平均每次预测时，模型感觉像在 50 个词里
    │     挑一个正确的；PPL 越低，概率估计越准，模型越强。
    └─ 推导结束：序列概率估计用链式法则把句子拆成步步预测，用 n-gram
       假设固定上下文，用平滑填平数据稀疏的坑，最后用困惑度统一衡量。
       这一整套框架就是统计语言模型的基石，也是现代神经语言模型的
       思想前身。

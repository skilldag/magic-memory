NAME
     1777552116227-transformer — 基于自注意力机制的序列到序列映射模型

SYNOPSIS
     输入序列 x = (x₁, ..., xₙ)  →  [编码器堆叠] → [解码器堆叠] → 输出序列 y = (y₁, ..., yₘ)

     核心组件: 多头自注意力, 位置编码, 残差流, 层归一化, 交叉注意力

DESCRIPTION
     本手册以“问题→解法→引发的新问题”递进推演, 逐层拆解 transformer 的设计脉络.
     所有公式均采用精简记号, 便于工程复现.

     ── 问题0: 序列建模中, RNN 串行慢, 长程梯度消散, 如何同时对全序列每一位置半行建模?
     │
     ├── 解决: 引入 自注意力 (Self-Attention), 让序列内任意两位置直接交互.
     │    │
     │    │   Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) V
     │    │
     │    │   Q, K, V 均由同一输入 X 经线性投影得到: Q = XW^Q, K = XW^K, V = XW^V
     │    │   · Q·Kᵀ 计算位置间相似度; 除以 √dₖ 防内积过大; softmax 归一化得权重.
     │    │   · 自注意力本质: 每个输出位置是对所有输入 V 的加权求和.
     │    │
     │    └── 引出问题: 单组 (Q,K,V) 投影空间表达能力有限, 不同位置的依赖类型易混淆.
     │
     ├── 解决: 多头注意力 (Multi-Head Attention)
     │    │
     │    │   MultiHead(Q,K,V) = Concat(head₁, ..., head_h) Wᴼ
     │    │   where headᵢ = Attention(QWᵢ^Q, KWᵢ^K, VWᵢ^V)
     │    │
     │    │   · 并行执行 h 个独立注意力, 捕捉不同子空间的依赖 (语法/语义/位置).
     │    │   · 拼接后经线性层 Wᴼ 融合.
     │    │
     │    └── 引出问题: 自注意力对位置不敏感, 排列不变性导致“词袋”困境, 丢失时序.
     │
     ├── 解决: 位置编码 (Positional Encoding)
     │    │
     │    │   PE(pos, 2i)   = sin( pos / 10000^(2i/d_model) )
     │    │   PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
     │    │
     │    │   · 将位置信息注入输入嵌入: X' = Embedding(x) + PE
     │    │   · 不同频率的正余弦组合确保相对位置可线性习得.
     │    │
     │    └── 引出问题: 深层网络直接堆叠上述模块, 梯度易消失, 收敛不稳定.
     │
     ├── 解决: 残差连接 + 层归一化 (Residual & LayerNorm)
     │    │
     │    │   Output = LayerNorm( x + Sublayer(x) )
     │    │
     │    │   · Sublayer 可为注意力或前馈网络 (FFN).
     │    │   · FFN 形如: max(0, xW₁+b₁)W₂+b₂ (两线性层间 ReLU).
     │    │   · 残差让梯度直通底层, LayerNorm 稳定隐性状态分布.
     │    │
     │    └── 引出问题: 上述构成编码器, 但如何用于“生成”任务? 生成时不能窥探未来.
     │
     ├── 解决: 掩码自注意力 (Masked Self-Attention) —— 解码器独有
     │    │
     │    │   Mask: 将 QKᵀ 中未来位置 (j>i) 的分数设为 -∞, softmax 后权重归零.
     │    │   因果约束: 位置 i 仅依赖 ≤i 的输入, 保障自回归生成.
     │    │
     │    └── 引出问题: 生成需要融合源信息, 解码器自身只有目标侧上下文.
     │
     └── 解决: 交叉注意力 (Cross-Attention) —— 解码器内
          │
          │   Q 来自解码器下层输出; K, V 来自编码器顶层输出.
          │   多头注意力作用同上, 将目标侧查询与源侧键-值对齐.
          │
          └── 引出问题: 单层编/解码器表达能力弱, 如何获得深度语义?

     ── 最终形态: 堆叠编码器-解码器
     │
     │   Encoder:  N × (多头自注意力 + FFN), 各子层套用残差+LayerNorm.
     │   Decoder:  N × (掩码自注意力 + 交叉注意力 + FFN), 同样残差归一化.
     │
     │   训练目标: 交叉熵损失 L = -∑ₜ log P_θ(yₜ|x, y_<ₜ)
     │   推理: 自回归逐词采样, 束搜索提高质量.
     │
     └── 由此构成完整 1777552116227-transformer 架构.

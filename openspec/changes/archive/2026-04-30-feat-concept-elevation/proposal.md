# Proposal: 概念提升功能

## 背景

当前 Magic Memory 系统中，用户在知识图谱视图阅读文档时，可以对文本添加评论、问题、建议、纠正等注释，但缺少一个关键功能：**将选中的文本快速提升为知识图谱中的新概念**。

## 问题

1. 用户在阅读文档时发现重要的概念术语，想要将其添加到知识图谱中
2. 当前需要通过其他方式手动创建概念，操作繁琐
3. 无法快速建立概念之间的关联关系

## 目标

实现"概念提升"功能：

1. **场景**：用户在知识图谱视图，已选中一个概念节点
2. **触发**：用户在文档中选中文字，点击"概念提升"按钮
3. **操作**：
   - 使用选中文字作为新概念的 `title`
   - 从当前选中的概念 (`selectedConcept`) 添加 `leads_to` 边指向新概念
   - 新概念的 `path` 置空（等待后续添加文档）
4. **跳转**：切换到知识图谱视图，聚焦到新概念节点

## 现有系统分析

### 存储结构
- **图索引**：`knowledgeGraphStore` 中存储 `concepts[]` 和 `edges[]`
- **概念来源**：`server.ts` 从 `docs/` 目录加载 Markdown 文档构建概念
- **概念 path**：每个概念通过 `path` 字段指向对应的 Markdown 文档

### 关键函数
- `createConceptWithEdges(source, input)` - 创建概念并建立边关系
- `selectedConcept` - 当前选中的概念（从 knowledgeGraphStore 获取）

### 简化版范围
- 固定关系类型为 `leads_to`（当前概念 → 新概念）
- 不调用 LLM 自动推荐关联概念
- 新概念 path 置空，等待后续填充

## 验收标准

1. 用户在文档中选中文字后，点击"概念提升"按钮
2. 系统创建新概念，title 为选中文字
3. 系统建立从当前概念到新概念的 leads_to 关系
4. 系统自动跳转到知识图谱视图，并聚焦到新概念节点
5. 新概念的 path 为空（或标记为待添加文档状态）

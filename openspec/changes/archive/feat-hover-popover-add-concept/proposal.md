# 图谱节点悬停浮层 — 概念添加快捷入口

## 问题

当前探索模式下，用户选中一个概念后，如果想基于图上的某个节点添加新概念（AI 生成或手动），需要在右上角固定位置的操作栏中操作。该操作栏离鼠标悬停的节点很远，交互不直观，用户不容易发现该功能。

## 方案

将现有的固定位置操作栏（`absolute top-3 right-16`）改为**在节点旁弹出的浮动浮层**：

1. 鼠标悬停到概念节点 → 节点旁弹出浮层
2. 浮层包含两个入口：**AI 生成探索**、**手动添加概念**
3. 点击入口按钮 → 复用已有的对话框（ExploreDialog / ManualLinkDialog）

### 关键要求

- 浮层位置紧贴节点右侧，自动处理边界溢出
- 鼠标移入浮层保持显示，移出后延迟隐藏
- 只改动浮层定位逻辑，不动对话框功能和 store 层
- 零新依赖

### 不做的范围

- 不改动 ExploreDialog 和 ManualAddDialog 的功能实现
- 不改动 KnowledgeGraph（Cytoscape）的渲染逻辑
- 不改动 store（addConcept / addEdge）

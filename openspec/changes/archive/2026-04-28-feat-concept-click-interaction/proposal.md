# 概念点击后的认知优先级 UI 交互优化

## 问题

当前用户点击概念后，右侧面板会较早进入关联展示。对首次接触该概念的用户来说，最先需要的是基础认知确认：

- 这个概念是什么
- 它解决什么问题
- 为什么这样命名
- 它与易混概念的区别

如果这些信息不先建立，后续关系浏览会变成“看连接但不理解”。

## 方案

将概念详情交互调整为“先理解，再推导”：

1. 默认优先展示基础认知信息（定义、问题、命名原因）
2. 增加“易混概念对比”区块，帮助建立概念边界
3. 将关联关系展示升级为“推导路径”表达（前置 → 当前 → 后继）
4. 关系展示附带简要原因，不仅给关系类型

## 目标

- 降低首次点击概念后的理解门槛
- 让关联浏览从“跳转列表”变成“可解释的推导过程”
- 提升用户继续探索的完成率

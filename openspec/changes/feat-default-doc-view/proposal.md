# Proposal: 概念详情面板默认显示查阅文档

## 现状

目前概念详情面板的四个操作按钮顺序为：
1. 梳理过程
2. 对照验证
3. 探索关联
4. 查阅文档

默认选中概念时显示「梳理过程」内容。

## 问题

- 用户选中一个概念时，最常做的是阅读其文档内容，而不是梳理过程
- 「查阅文档」按钮在最右边，不符合用户使用频率
- 每次选中概念都需要手动切换到「查阅文档」tab

## 方案

1. 将「查阅文档」按钮移到最左边（第一个位置）
2. 默认选中概念时显示「查阅文档」内容

## 影响范围

- `src/components/ConceptDetailPanel.tsx` — 修改 actions 排序和默认 state

# 骨架填充流程

## 问题

首次进入过程画板时，用户对该概念的「过程」是未知的：

1. **空白画板太冷启动** — 用户不知道过程长什么样，无从下手
2. **信息面板太被动** — 只看不操作，没有认知参与
3. **过程动画不现实** — 每个概念定制动画成本太高

核心矛盾：第一次接触需要**有结构的引导**，但必须是**主动参与**而非被动接收，且不能是**记忆测试**。

## 方案

先给出骨架流程（空缺节点 + 引导问题）→ 用户拖拽候选概念填充 → 提交验证 → 用户提问补充不理解的点。

### 核心流程

```
双击概念 → 骨架画板（空缺节点 + 引导问题）
              ↓ 从候选区拖拽概念填空
           提交 → 正确/错误逐项反馈
              ↓ 有疑问？
           提问 → 沉淀问题集 / 转化为新概念 / 补充为流程步骤
              ↓ 想深入？
           点击子概念 → 子概念骨架画板（递归）
```

### 关键设计

- 空缺节点展示**问题**而非概念名，驱动思考
- 候选概念区供拖拽，也可创建自定义节点
- 提交后逐项验证填充结果
- 提问可转化为新概念节点或补充为过程步骤

### 不做的事

- 不做过程动画/自动播放
- 不改变自由画板（拖拽/连线）的交互
- 问题→概念/步骤的转化由用户确认
